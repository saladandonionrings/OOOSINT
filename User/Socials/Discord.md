# How to Get a User's ID

## Step 1: Enable Developer Mode

1. Go to **User Settings** (your settings).
2. Scroll down to the bottom of the left sidebar and click on **Developer**.
3. Toggle **Developer mode** to **ON**.
    
```
[User Settings] ➔ [Developer] ➔ Toggle "Developer mode"
```

## Step 2: Copy the User ID

1. Navigate to the profile of the user you want to choose.
2. Click on their **profile picture** or **name** to open their profile card.
3. Click on the **`...`** (three dots) icon in the top right corner of their profile.
4. Select **Copy user ID** from the drop-down menu.
